# Lumary OS — Vocabulary

Lumary OS introduces a proprietary vocabulary to reframe how we think about web experiences. These terms replace generic industry language with experience-focused alternatives.

---

## Glossary

| Conventional Term | Lumary OS Term | Rationale |
|---|---|---|
| Hero / Hero Section | **Arrival Scene** | The user doesn't "hero" — they *arrive*. This is the first moment of the experience. |
| Scroll Animation | **Story Progression** | Motion triggered by scroll isn't decoration — it advances the narrative. |
| Hover Effect | **Interaction Reward** | Every hover should reward the user with feedback. If it doesn't, it's wasted. |
| Component | **Experience Primitive** | These are not UI components. They are the atomic units of an experience. |
| Section | **Narrative Block** | Pages tell stories. Sections are chapters. |
| Page Load | **The Curtain Rise** | The moment before content appears sets the tone. Treat it as theater. |
| CTA Button | **Decision Point** | A call-to-action isn't a button. It's a moment of choice. Design it as such. |
| Navigation | **Orientation System** | Users don't navigate. They orient themselves. The system should guide, not list. |
| Loading Spinner | **Anticipation Frame** | Wait time is an opportunity for wonder, not frustration. |
| Footer | **The Closing Note** | The last thing users see should leave a lasting impression. |
| Onboarding | **The Invitation** | First use is not training. It's welcoming. |
| 404 Page | **The Recovery Scene** | Errors are moments to delight, not frustrate. |
| Empty State | **The Beginning Canvas** | Empty = potential, not absence. |
| Form Field | **Data Dialogue** | Every input is a question. Every validation is an answer. |
| Error Message | **Guidance Signal** | Errors are wayfinding, not punishment. |
| Tooltip | **Whisper** | Quiet, contextual help that doesn't interrupt. |
| Modal / Dialog | **Focused Moment** | A full-attention frame for critical decisions. |
| Card | **Content Vignette** | A self-contained story, not a layout box. |
| Divider | **Breath** | Visual pause that gives the eye rest. |
| Progress Bar | **Journey Marker** | Signals how far they've come and what remains. |

---

## Usage Guidelines

- Use Lumary OS vocabulary in **all internal documentation**
- Use conventional terms when **communicating with clients** (unless they buy into the philosophy)
- Explain the terminology shift when **onboarding new team members**
- Reference terms in **AI prompts** to guide the agent's design language

---

## Why This Matters

Language shapes thinking. By replacing "hero section" with "arrival scene," designers naturally start thinking about the emotional quality of the first impression rather than the layout of a container.

This is not branding. It's cognitive reframing.
