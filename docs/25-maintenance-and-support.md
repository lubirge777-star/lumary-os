# Maintenance & Support

## Version 1.0

---

## Philosophy
A website is not a one-time product. It is a living asset. Regular maintenance ensures security, performance, and relevance. Support plans turn one-time projects into recurring revenue.

---

## Maintenance Plans

### Plan A: Basic — 50,000 TZS/month
- Monthly security update check
- Uptime monitoring
- Form submission monitoring
- Email support (response within 24h)
- 1 hour of content changes

### Plan B: Standard — 100,000 TZS/month
- Everything in Basic
- Monthly performance report
- Quarterly content updates (up to 3 pages)
- Phone/WhatsApp support
- Monthly backups
- Plugin/library version checks

### Plan C: Growth — 200,000 TZS/month
- Everything in Standard
- Monthly new content (1 new page or section)
- Social media integration updates
- SEO monthly report
- Priority support (response within 4h)
- Competitor monitoring

---

## Maintenance Tasks

### Weekly
- Check form submissions (verify working)
- Review analytics for anomalies
- Uptime check

### Monthly
- Update content as requested
- Check for broken links
- Review Core Web Vitals
- Plugin/library security check
- Backup website
- Performance report to client (Standard+)

### Quarterly
- Content refresh (update photos, team, portfolio)
- SEO review (rankings, keywords)
- Competitor website check
- Technology update recommendations

### Annual
- Full design review
- Domain renewal reminder
- Hosting renewal reminder
- SSL certificate check
- Major version updates

## Support SLA

| Issue Severity | Response Time | Resolution Time |
|---|---|---|
| Critical (site down) | 1 hour | 4 hours |
| High (form broken) | 4 hours | 24 hours |
| Medium (visual bug) | 24 hours | 48 hours |
| Low (content update) | 48 hours | 5 business days |

---

## Emergency Protocol

```
SITE DOWN:
  1. Check hosting status
  2. Check domain/SSL expiry
  3. Restore from latest backup
  4. Notify client with ETA
  5. Investigate root cause
  6. Document incident

FORM NOT WORKING:
  1. Check form handler/service
  2. Test submission
  3. Check email configuration
  4. Verify spam folder
  5. Notify client when resolved
```
