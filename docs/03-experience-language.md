## What is Experience Language?

Experience Language is the vocabulary we use to describe how a user *feels* as they navigate a digital product.

Most design systems define colors, fonts, and components. Experience Language defines emotional states, interaction qualities, and narrative arcs.

It is the bridge between business goals and user psychology.

---

## The Five Dimensions

Every experience can be described along five dimensions:

### 1. Energy

How much visual and interactive intensity does the experience carry?

| Level | Description | Best For |
|---|---|---|
| Low | Sparse, calm, slow transitions | Luxury, professional services |
| Medium | Balanced motion, moderate color | SaaS, corporate |
| High | Bold typography, dynamic animation | Entertainment, creative studios |

### 2. Formality

How structured and conventional is the layout?

| Level | Description | Best For |
|---|---|---|
| Formal | Grid-based, symmetrical, predictable | Law, finance, consulting |
| Semi-formal | Grid with asymmetrical accents | Tech, real estate |
| Informal | Asymmetrical, experimental, artistic | Creative agencies, fashion |

### 3. Warmth

How human and approachable does the experience feel?

| Level | Description | Best For |
|---|---|---|
| Cold | Minimal, distant, highly polished | Luxury, tech |
| Neutral | Professional but friendly | SaaS, corporate |
| Warm | Personal, conversational, human | Hospitality, wellness |

### 4. Depth

How layered and dimensional is the visual experience?

| Level | Description | Best For |
|---|---|---|
| Flat | 2D, minimal shadow, clean | Modern tech startups |
| Elevated | Subtle shadows, layered cards | Most businesses |
| Immersive | Parallax, 3D, glassmorphism | Real estate, tourism |

### 5. Tempo

How fast does the experience unfold?

| Level | Description | Best For |
|---|---|---|
| Slow | Deliberate reveals, long transitions | Luxury, storytelling |
| Moderate | Balanced pace | Most applications |
| Fast | Quick transitions, instant feedback | Productivity, dashboards |

## Experience Profiles

An Experience Profile is a combination of the five dimensions. Every project we build must have a defined profile.

### Example: Premium Construction Company

```
Energy:    Medium
Formality: Formal
Warmth:    Neutral
Depth:     Elevated
Tempo:     Moderate
```

### Example: Luxury Restaurant

```
Energy:    Low
Formality: Semi-formal
Warmth:    Warm
Depth:     Immersive
Tempo:     Slow
```

### Example: Creative Agency

```
Energy:    High
Formality: Informal
Warmth:    Warm
Depth:     Immersive
Tempo:     Fast
```

---

## How to Define an Experience Profile

1. **Understand the business identity** — What does this brand stand for?
2. **Understand the audience** — Who is visiting? What state of mind are they in?
3. **Understand the conversion goal** — What action must the visitor take?
4. **Map to dimensions** — Score 1-3 on each dimension.
5. **Document** — Save the profile in the project brief.

---

## Experience Anti-Patterns

| Anti-Pattern | Result |
|---|---|
| High energy + Formal | Chaotic, conflicting signals |
| Slow tempo + High energy | Fatigue, impatience |
| Cold + No depth | Feels empty, forgettable |
| Warm + Fast tempo | Feels rushed, impersonal |
| Immersive + Low performance | Frustration, abandonment |
