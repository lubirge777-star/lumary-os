Design Research

Notes from the exploration of liquid navigation patterns in modern UI.

On Morphing Interfaces

The concept of a navigation bar that changes its physical properties in response to scroll position draws from material physics. At rest, the nav is substantial — grounded. As the user descends into content, it sheds mass, becoming a lightweight contextual overlay. This mirrors how our peripheral vision narrows when focusing on a task.

Key to the illusion is the easing curve: cubic-bezier(0.22, 1, 0.36, 1). This custom easing gives the transition a natural deceleration — like a door sliding into its frame with a soft pneumatic dampener. No linear movements. No jarring stops.

Magnetic Hover as Affordance

Traditional link hovers change color. Magnetic hover goes further by adding a spatial dimension — the link text shifts in the direction of the cursor, creating a physical pull. This is implemented by tracking mousemove events over each link and applying a clamped delta to a transform: translate() on the text span.

The maximum displacement is kept small (~4px) so it reads as a micro-interaction rather than a distracting animation. Combined with a radial gradient "glow" that follows the cursor, the effect is subtle but deeply satisfying.

Glassmorphism Constraints

backdrop-filter: blur(18px) provides the frosted-glass effect. On scroll, the background alpha drops from 0.85 to 0.72, letting more of the page content show through. The border lightens in opacity to maintain legibility. A box-shadow with 40px spread adds a soft atmospheric halo that separates the nav from the background.

Care must be taken on low-end devices: will-change hints are set on animated properties and the blur radius is kept moderate to avoid jank. On mobile, the backdrop-filter is applied only when scrolled to minimize compositing cost.

Performance Strategy

All animations are GPU-composited where possible: transform and opacity for the magnetic effect, height and backdrop-filter for the nav morph. The scroll handler uses a passive listener with a requestAnimationFrame throttle to stay at 60fps even during rapid scrolling.

On mobile, the backdrop-filter on the nav is toggled only when scrolled, and the hamburger menu uses translateX for the slide-in panel — avoiding layout thrashing by reading scrollY only once per frame.

Documentation

Implementation notes, CSS custom properties API, and usage guidelines.

CSS Custom Properties API

The component is fully themed via CSS custom properties defined on :root. Override any value to customize: --nav-height, --nav-bg, --accent, , --ease-smooth, and --radius for shape control. The nav reads --mx and --my custom properties for the radial gradient cursor glow.

Scroll State Machine

A scrolled CSS class is toggled on the <nav> element when window.scrollY > 100. The CSS handles all visual transitions via the declared transition rules. No JS-driven inline styles for the morph — keeping style logic in CSS where it belongs.

Magnetic Effect Details

Each .nav-link gets a mousemove listener that computes the delta between the cursor and the link center, then applies a clamped translate(x, y) on the .link-text child. On mouseleave, the transform smoothly returns to zero via the CSS transition rule.
