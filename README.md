# Lumary OS

**The operating system for experience-driven web design.**

A comprehensive methodology, design system, motion language, and experience database for building premium digital experiences.

---

## What is Lumary OS?

Lumary OS is not a template library. It is not a component kit. It is not documentation.

It is an **operating system** for building websites that make users *feel something*.

We do not sell websites. We sell emotional outcomes.

## Core Principles

1. **Emotion First** — Every design choice answers: *What should the user feel?*
2. **Motion with Meaning** — Every animation serves Guide / Feedback / Narrative
3. **60-30-10 Color Rule** — 60% dominant, 30% secondary, 10% accent
4. **8px Grid** — All spacing is multiples of 8
5. **Mobile First** — Design for 375px before 1440px
6. **Performance is UX** — 90+ Lighthouse or it's not finished
7. **One Primary Action** — Exactly one CTA per viewport
8. **3-5 WOW Rule** — 3 to 5 memorable moments per page
