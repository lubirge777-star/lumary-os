# ✦ Lumary OS

**Experience Engineering — The operating system for building digital experiences people remember.**

---

## 🧠 Why Lumary OS Exists

The internet has become predictable.

Websites are collections of components rather than experiences. Every page follows the same template: hero, features, testimonials, footer. Users have learned to tune out.

Lumary OS exists because **people remember emotions, not layouts**.

They remember the first impression. The unexpected moment. The delight of an interaction that felt *alive*. They forget everything else.

This system is a methodology for engineering those moments — systematically, repeatably, at scale.

---

## 🎯 What Lumary OS Is

Lumary OS is **not** a template library. It is **not** a component kit. It is **not** documentation.

It is an **operating system** for building websites that make users *feel something* — backed by a design system, motion language, experience database, business playbooks, AI-ready agent skills, scoring tools, experimental prototypes, and case study analysis.

---

## ✦ We Believe

- **Technology should disappear** — Users should feel the experience, not the stack.
- **Interfaces should breathe** — Space is not emptiness. It's readability, focus, and clarity.
- **Motion should educate** — Every animation guides, orients, or rewards. No movement without purpose.
- **Performance creates trust** — A slow site signals incompetence. 90+ Lighthouse or it's not finished.
- **Interaction is conversation** — Every hover, click, and scroll is a dialogue between user and interface.
- **Curiosity beats information** — Reveal progressively. Make users *want* to discover more.
- **Beauty follows clarity** — The most beautiful interfaces are the easiest to understand.

---

## 🏛️ The Five Pillars

Everything in Lumary OS belongs under one of these pillars:

### ❤️ Emotion
The target feeling defines every decision — color, typography, pacing, motion, voice. We design for emotional outcomes first, aesthetic outcomes second.

### 📖 Story
Every page has a beginning, middle, and end. Information is revealed progressively. The user is guided, not dumped.

### 🎬 Motion
Animation is not decoration. It is orientation (where am I?), feedback (what just happened?), and narrative (what comes next?). Every animation serves one of these three.

### 🔧 Craft
The gap between good and premium is in the details — spacing, timing, easing, contrast, consistency. Craft is what separates "it works" from "it feels right."

### ⚡ Performance
Speed is a feature. A beautiful page that takes 5 seconds to load is ugly. We ship fast or we don't ship.

## 🔬 Experience Engineering

Lumary OS introduces a new discipline: **Experience Engineering**.

Most people know UI Design, UX Design, Product Design, Motion Design, Frontend Engineering, and Interaction Design — but no single discipline owns the end-to-end *emotional outcome*.

Experience Engineering bridges this gap.

```text
✦ Lumary OS

↓

✦ Experience Engineering

↓

Experience Architecture → Experience Database → Experience Patterns

↓

Experience Scoring → Experience Metrics
```

Every project follows the **Experience Lifecycle**:

```text
🔍 Research

↓

💭 Emotion Mapping (What should the user feel?)

↓

📋 Story Architecture (In what order?)

↓

✏️ Wireframe (Where does it go?)

↓

🎨 Experience Design (What WOW moments?)

↓

🔄 Motion Design (How does it move?)

↓

💻 Development (Build)

↓

📈 Optimization (Performance + accessibility)

↓

🚀 Launch

↓

♻️ Evolution (Measure + iterate)
```

## 🚀 Getting Started

### Explore the System

```bash
# Read the manifesto
cat docs/00-manifesto.md

# Study the psychology
cat psychology-atlas/why-humans-remember.md

# Browse experiences
ls experience-db/
cat experience-db/arrival/exp-001-awakening.md
```

### Analyze a Real Site

```bash
# Read the Apple Vision Pro deconstruction
cat case-studies/apple-vision-pro.md
```

### Run the Recommendation Engine

```bash
python experience-ai/recommendation-engine.py --industry saas --emotion trust
python experience-ai/recommendation-engine.py --industry fashion --emotion luxury --verbose
python experience-ai/recommendation-engine.py --interactive
```

### Score Your Work

```bash
# Quick demo
python metrics/lumary-score.py --quick

# Manual scoring
python metrics/lumary-score.py --curiosity 85 --memory 78 --interaction 72 --motion 80 --cognitive 88 --conversion 90 --performance 95 --accessibility 92

# Save and compare reports
python metrics/lumary-score.py --quick --save report-a.json
python metrics/lumary-score.py --quick --save report-b.json
python metrics/lumary-score.py --compare report-a.json report-b.json
```

### View the Lab Prototype

Open `labs/liquid-navigation/index.html` in your browser — a working nav bar with scroll-triggered glassmorphism and magnetic hover links.

### Build Premium Sites

```bash
# ONE-SHOT: Build a premium site in minutes
cat skills/opencode/lumary-pro-max.md

# Standard: Implement from Stitch design
cat prompts/opencode/implement-from-stitch.md
```
