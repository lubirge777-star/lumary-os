## Overview
From final payment to handoff — how we deliver a complete, polished website to the client.

---

## Pre-Delivery Checklist

### 24 Hours Before Delivery
- [ ] Run full QA checklist (docs/23-quality-assurance.md)
- [ ] Test all forms end-to-end
- [ ] Verify all links (internal + external)
- [ ] Check all pages at all breakpoints
- [ ] Run Lighthouse audit (90+ all categories)
- [ ] Verify analytics events fire correctly
- [ ] Test WhatsApp button
- [ ] Verify Google Maps embed
- [ ] Check custom domain (if applicable)
- [ ] SSL certificate valid
- [ ] Backup the site
- [ ] Prepare handoff document

## Post-Delivery

### Immediately After
1. Send thank-you message
2. Request testimonial (use template)
3. Request Google review
4. Ask for referrals (offer 10% commission)
5. Add client to maintenance list

### 1 Week After
1. Follow up: "How is everything working?"
2. Check form submissions
3. Verify analytics

### 1 Month After
1. Check for any issues
2. Offer maintenance plan renewal
3. Share any performance insights
