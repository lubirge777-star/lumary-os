# Stitch Prompt: Component Generator

## Version 1.0

## Template
```
Design a [COMPONENT TYPE] component for a [INDUSTRY] website.

Style: [minimal / luxury / corporate / creative]
Theme: [dark / light]
Colors: [primary color], [accent color]

Requirements:
- [Requirement 1]
- [Requirement 2]
- [Requirement 3]

The component should feel premium, modern, and aligned with Lumary OS design language (8px grid, medium radius, subtle shadows, max 2 fonts).
```

## Examples

### Card Component
```
Design a service card component for a construction company website.
Style: Minimal, dark theme
Colors: Slate black, amber accent
Include: icon, title, description, optional hover link
```

### Testimonial Card
```
Design a testimonial card for a restaurant website.
Style: Warm, dark brown theme
Colors: Burnt orange accent
Include: star rating, quote, guest name, photo placeholder
```

### Pricing Card
```
Design a pricing card for a SaaS company.
Style: Corporate, dark navy theme
Colors: Blue accent
Include: plan name, price, features list, CTA button
```
