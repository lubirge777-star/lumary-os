# Stitch Prompt: Landing Page Generator

## Version 1.0

---

## Purpose
Generate premium, animated landing page mockups in Stitch for any business or industry.

---

## Prompt Template

```
Create a modern, premium landing page design for a [INDUSTRY] company called [COMPANY NAME].

Style: [minimal / luxury / corporate / creative]
Primary emotion: [trust / excitement / calm / desire]
Color preference: [dark mode / light mode / specific colors]

The page should include these sections:
1. Hero section with:
   - Large, bold heading communicating [CORE VALUE PROPOSITION]
   - Short subheading explaining [BENEFIT]
   - Primary CTA button: [CTA TEXT]
   - Full-width background image/video area
   - Optional: floating navigation bar that transitions transparent → solid

2. Social Proof section (optional):
   - Client logos (3-5)
   - Or statistics (years, projects, clients)

3. Services/Features section:
   - [NUMBER] cards in a grid layout
   - Each card: icon + title + short description
   - Cards should have hover state indication

4. Portfolio/Projects section:
   - Gallery grid with [NUMBER] items
   - Each item: image overlay with title on hover

5. Testimonials section:
   - Carousel or grid layout
   - Each: quote + name + title + photo placeholder

6. CTA section:
   - Bold heading
   - Supporting text
   - Primary CTA button

7. Footer:
   - Logo
   - Navigation links
   - Social media icons
   - Copyright text

Design principles:
- Generous whitespace (60%+ negative space)
- 60-30-10 color distribution
- Consistent rounded corners (medium radius)
- Subtle shadows
- Mobile-first responsive layout
- Maximum 2 font families
- Clear visual hierarchy

Animation notes (for development reference):
- Hero: staggered text reveal (heading → sub → CTA)
- Sections: fade-in on scroll
- Cards: hover lift effect
- Counters: animate on scroll into view
- Navigation: transparent → glassmorphism on scroll
```

```
Add: Project stats (years, buildings, clients)
Add: Before/after image comparison
Add: Safety certifications badge
Add: Quote request form in hero (secondary)
Visual focus: Cinematic project photography, amber accents
```

## Export Instructions

After generating in Stitch:
1. Export as design spec or image mockup
2. Identify primary, secondary, accent colors (hex values)
3. Note font family choices
4. Document section order
5. Highlight unique animation opportunities
6. Forward to OpenCode for implementation
