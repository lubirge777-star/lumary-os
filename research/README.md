# Research — Evidence-Based Experience Design

## Why

Lumary OS is not opinion — it's evidence.

This directory catalogs the cognitive science, psychology, and usability research that informs every design decision in the system. Every principle in Lumary OS should trace back to a study or established theory.

---

## Contents

### 🧠 Cognitive Psychology

| Topic | File | Key Insight |
|-------|------|-------------|
| **Fitts's Law** | `fitts-law.md` | Larger, closer targets are faster to acquire — nav items, CTAs, touch targets |
| **Hick's Law** | `hick-law.md` | More choices = slower decisions — limit navigation items, form fields, pricing tiers |
| **Miller's Law** | `miller-law.md` | Working memory holds ~7±2 items — chunk information, limit menu items |
| **Cognitive Load** | `cognitive-load.md` | Minimize extraneous load, optimize germane load — clean layouts, progressive disclosure |
| **Serial Position Effect** | `serial-position.md` | First and last items are most recalled — place key CTAs at page start/end |
| **Von Restorff Effect** | `isolation-effect.md` | Distinctive items stand out — make the primary CTA visually unique |

### ⚡ Attention & Focus

| Topic | File | Key Insight |
|-------|------|-------------|
| **Attention Span** | `attention.md` | Average attention on digital content is ~8 seconds — hook immediately |

## How to Use

When designing a Lumary OS experience, reference the relevant research:

1. **Hero / Arrival Scene** → Reading patterns, attention span, emotional design
2. **Navigation** → Fitts's Law, Hick's Law, Jakob's Law
3. **Forms** → Hick's Law, Fitts's Law (touch), cognitive load
4. **Motion** → Change blindness, Doherty Threshold, peak-end rule
5. **CTA** → Von Restorff effect, serial position effect, trust signals
6. **Pricing** → Hick's Law, anchoring, cognitive load
