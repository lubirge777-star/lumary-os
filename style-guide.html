Design Principles

The foundational beliefs that guide every decision in Lumary OS.

01

Experiences Over Features

Don't just list what you do. Make people feel something. Every interaction should leave an emotional imprint.

02

Progress Over Polish

Ship fast, iterate faster. Lumary OS is designed to be modular and composable so you can launch quickly and refine continuously.

03

Accessibility Is Not Optional

WCAG 2.1 AA is the floor, not the ceiling. Skip links, reduced motion, semantic HTML, ARIA — every template ships fully accessible.

04

Consistency Through Systems

One design token set, one component architecture, one experience vocabulary. Every template is built from the same atomic pieces.

How Layers Compose

Tokens inform every experience. Experiences are combined into patterns. Patterns are assembled using components. Components are wired together in templates. Each layer references the one below it. This means changing a token in the Color Bible automatically cascades through every template. Experiences like The Awakening (hero) and The Counter (stats) can be mixed and matched across any template without code changes.

Getting Started

Lumary OS is designed to be consumed in layers. Here's the recommended path for different roles.

For Developers

Start with the Component Bible (4 systems), then explore the Pattern Library (8 types). Use templates as reference implementations. Key docs: 10-Component System, 16-Development Workflow.

For Designers

Begin with the Color Bible, Motion Bible, and Psychology Atlas. Then study the Experience Database for interaction patterns. Key docs: 06-Design Language, 07-Motion Language.

For Strategists

Read the Manifesto and Philosophy first. Then explore the Business Model and Client Onboarding docs. Use playbooks for operational guidance. Key docs: 00-Manifesto, 17-Business Model.

Signature Experiences

The core experiences that define Lumary OS. Each is a reusable, composable interaction pattern.

001

The Awakening

Cinematic staggered reveal for hero sections. Orchestrates background, headline, subtext, and CTA in a choreographed sequence. Used in all templates as the primary arrival experience.

ProductionArrival
002

The Cascade

Staggered card reveal for service/feature grids. Each card fades and translates upward in sequence, creating a waterfall effect. Used in every template for feature showcases.

ProductionCards
004

The Counter

Animated stat counters that increment on scroll. Uses GSAP snap for integer precision. Configurable target, suffix, and duration. Present in all templates for trust-building.

ProductionScroll
005

Magnetic Nav

Navigation links that follow the cursor with elastic easing. Creates a playful, premium feel. Applied to all nav-link elements across every template.

ProductionNavigation
007

Tilt Card

3D perspective tilt on hover for service/feature cards. Subtle rotation based on cursor position. Enhances the tactile feel of interactive cards.

ProductionCards
021

Timeline Scroll

Animated timeline items that fade and slide in on scroll. Used in the About section to tell company history. Each item animates with a staggered delay.
