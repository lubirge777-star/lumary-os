## Industry Presets

### Construction
```
Style: Dark + industrial
Palette: Slate black / Dark navy / Amber
Font: Bebas Neue (headings) + DM Sans (body)
Key visual: Cinematic project photography, blueprints, hard hats
```

### Luxury
```
Style: Minimal + elegant
Palette: Near-black / Dark gray / Gold
Font: Playfair Display (headings) + Inter (body)
Key visual: High-contrast product shots, negative space
```

### Restaurant
```
Style: Warm + intimate
Palette: Dark brown / Deep brown / Burnt orange + cream
Font: Cormorant Garamond (headings) + Nunito (body)
Key visual: Food photography, ambient dining shots
```

### SaaS / Tech
```
Style: Clean + modern
Palette: Navy / Slate / Blue
Font: DM Sans (headings) + Inter (body)
Key visual: Dashboard screenshots, clean UI elements
```

### Creative Agency
```
Style: Bold + experimental
Palette: Black / Dark gray / Purple or vibrant accent
Font: Space Grotesk (headings) + Sora (body)
Key visual: Portfolio pieces, bold typography
```
