# Certification — Lumary OS Mastery Program

## Levels

### 🥉 Bronze (Foundation)
**Requirements:**
- Complete one Lumary OS project (any template)
- Score 70+ on Lumary Score
- Demonstrate understanding of 3 experience patterns
- Pass philosophy quiz

**Privileges:**
- Bronze badge for portfolio
- Access to community projects

---

### 🥈 Silver (Practitioner)
**Requirements:**
- Complete 3 Lumary OS projects across different industries
- Score 80+ on all projects
- Demonstrate 10+ experience patterns from database
- Write one case study
- Pass motion principles assessment

**Privileges:**
- Silver badge
- Early access to new patterns
- Mentor Bronze candidates
- Listed on Lumary directory

---

### 🥇 Gold (Expert)
**Requirements:**
- Complete 10 Lumary OS projects
- Score 90+ on all projects
- Create 3+ original experience patterns
- Published case studies (2+)
- Demonstrate understanding of all 20 experience categories
- Pass psychology atlas assessment
- Peer review for Silver candidates

**Privileges:**
- Gold badge
- Pattern contributor status
- Revenue share on marketplace patterns
- Priority support
- Featured in Lumary OS gallery

---

### 👑 Master (Architect)
**Requirements:**
- Complete 25+ Lumary OS projects
- Score 95+ on all projects
- Create 10+ original experience patterns
- Publish 5+ case studies
- Contribute to Lumary OS methodology
- Train new Gold candidates
- Deliver at least one talk or workshop

**Privileges:**
- Master badge
- Pattern contributor status + enhanced revenue share
- Methodology contributor credit
- Lumary OS advisory board invite
- Co-author future versions of methodology docs

---

## Assessment Process

1. **Self-assessment** — Submit project with Lumary Score report
2. **Peer review** — Gold+ certifiers review project
3. **Score verification** — Independent Lumary Score audit
4. **Knowledge check** — Assess understanding of relevant principles
5. **Certification awarded** — Badge + certificate

---

## Tools

- `certification/assess.py` — CLI to evaluate project against certification criteria
- `certification/checklist.md` — Detailed checklist for each level
- `certification/audit.md` — External audit template
