# Lumary OS — OpenCode Skill

## Name
lumary-os

## Description
Full-stack Experience Engineering system for building premium, animated digital experiences. Includes philosophy, design system, experience database (54+ cataloged interactions), pattern library, component/motion/color bibles, psychology atlas, metrics framework, AI skills, business playbooks, and 7 production templates (avg 4.93/5). Use when building websites that need to feel premium, animated, emotionally-targeted, and conversion-optimized.

## Workflow

### 1. Determine Requirements
Ask or extract:
- Business name and industry
- Primary goal and target emotion
- Color preference (dark/light)
- Sections needed
- WOW moments (3-5 from experience-db/)

### 2. Philosophy Check
- Which of the Five Pillars is most important? (Emotion, Story, Motion, Craft, Performance)
- What should the user feel? (Trust, Excitement, Calm, Desire, Curiosity)

### 3. Select Experience Profile
Map industry → emotion → Experience Profile (Energy/Formality/Warmth/Depth/Tempo) from docs/ and color-bible/

### 4. Build Using System
- Use templates/templates/ as starting point
- Add experiences from experience-db/
- Follow patterns from patterns/
- Use component specs from component-bible/
- Reference motion specs from docs/14-motion-bible.md
- Apply psychology from docs/15-psychology-atlas.md

### 5. Quality Check
Run checklist from docs/23-quality-assurance.md + metrics/README.md:
- Visual QA
- Responsive QA (375-1536px)
- Functional QA (all links, forms, interactions)
- Performance QA (Lighthouse 90+)
- Accessibility QA (WCAG AA)
- Content QA (no placeholders)
- Lumary Score calculation (8 dimensions)

### 6. Deploy
- Deploy to Vercel
- Verify custom domain and SSL
- Handoff per playbooks/delivery-playbook.md

## Core Concepts

### The Five Pillars
1. **Emotion** — Every design choice answers: "What should the user feel?"
2. **Story** — Every page has a beginning, middle, and end
3. **Motion** — Every animation guides, orients, or rewards
4. **Craft** — Premium is in the details (spacing, timing, easing, contrast)
5. **Performance** — 90+ Lighthouse or it's not finished

### The Experience Lifecycle
Research → Emotion Mapping → Story Architecture → Wireframe → Experience Design → Motion → Development → Optimization → Launch → Evolution

### The Lumary Score
Curiosity | Memory | Interaction Density | Motion Density | Cognitive Load | Conversion Readiness | Performance | Accessibility → Overall (0-100)
