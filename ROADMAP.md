# Lumary OS v4.0 — Ecosystem Vision

## From Documentation → Platform

v3.0 established Lumary OS as a methodology. v4.0 transforms it into an ecosystem.

---

## The Stack

```text
Lumary OS v4.0

├── CLI (lumary)
│   ├── lumary init          # Scaffold new project
│   ├── lumary score         # Run Lumary Score against project
│   ├── lumary recommend     # Get experience recommendations
│   ├── lumary analyze       # Audit existing site for Lumary Score
│   ├── lumary build         # Generate production template
│   └── lumary cert          # Run certification assessment
│
├── Framework (lumary-js)
│   ├── npm package
│   ├── React / Vue / Svelte adapters
│   ├── <ArrivalScene> component
│   ├── <StoryProgression> hook
│   ├── useInteractionReward()
│   └── Built-in Lenis + GSAP integration
│
├── VS Code Extension
│   ├── Lumary Score inline annotations
│   ├── Experience snippet library
│   ├── Live preview overlays
│   ├── Motion timeline inspector
│   └── One-click template scaffolding
│
├── Experience Inspector (DevTools)
│   ├── Browser extension (Chrome, Firefox, Edge)

├── AI Assistant
```

## What v4.0 Does NOT Do

- **Add more files** — The documentation is complete. v4.0 is about tooling, not content.
- **Replace agency work** — The ecosystem accelerates quality but doesn't automate creativity.
- **Lock users in** — All patterns remain vanilla HTML/CSS/JS. The framework is optional.
