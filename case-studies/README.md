# Case Studies — Reverse-Engineered Experience Analysis

## Why

The best way to learn experience design is to study the best.

This folder contains reverse-engineered analyses of digital experiences from world-class products. Not copies. **Deconstructions** — breaking down *why* something feels premium, *how* the experience is architected, and *what* Lumary OS can learn from it.

---

## Methodology

Each case study follows the same structure:

```text
1. Product & Context
   - What does this experience do?
   - Who is it for?
   - What emotion does it evoke?

2. Experience Breakdown
   - Typography (why this font, this scale, this hierarchy)
   - Spacing & Layout (rhythm, density, alignment)
   - Motion (what moves, when, how fast, what easing)
   - Color & Contrast (palette logic, accessibility)
   - Interaction Design (hover, click, scroll, transition)
   - Micro-copy (tone, voice, pacing)

3. Psychological Principles Applied
   - Which cognitive biases are leveraged?
   - Which emotional triggers are activated?

4. Lumary Learnings
   - How to implement this in Lumary OS
   - Which patterns/experiences to use
   - Code snippets where applicable

5. Lumary Score
   - Curiosity, Memory, Interaction Density, Cognitive Load, Performance
```

## How to Contribute

1. Choose a product from the list (or propose one)
2. Spend 30+ minutes interacting with it — take notes, screenshots, recordings
3. Deconstruct each layer using the methodology above
4. Write up findings and add to this folder
5. Link to the corresponding Lumary OS patterns/experiences used
